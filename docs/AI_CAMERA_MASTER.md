# 통합 AI 카메라 MASTER / 2026-10-29

## 목표
Galaxy Z Fold7/Flip3 Android 카메라 앱을 주 앱으로 개발한다. 사진·동영상·책/문서·골프·수목·번역·측량 탭을 나란히 배치한다. 골프 AI와 감정평가 AI는 각각 기존 자료/서비스를 보존하며 공유 데이터 인터페이스로 연동한다.

## 현재 실제로 작성한 코드의 구분
- [x] **웹 개발 소스**: /camera 웹 허브, /camera/golf 초슬로 영상 파일·프로 비교·2D 관절각·단계 탐색·교정 기록, /camera/trees 수종 백엔드 연계 UI·참조물 직경, /camera/survey 기준물 기반 2D 거리·면적·건물 외곽 및 AR 지오메트리 수학
- [x] **네이티브 별도 소스**: CameraX 촬영·배율·화질 우선, ML Kit 실시간 식물 대분류·OCR·영문→한글, Google ML Kit 문서 스캐너, ARCore Depth hitTest 실제 3D 지점 거리/면적, outdoor BUILDING/TREE semantic fraction, 알림 있는 사용자 시작 background 녹화/간격 사진. 현재 이 소스는 대화 파일로 제공; 기존 저장소 변경으로 착각 금지.
- [ ] **운영 앱/실기기**: 네이티브 APK 빌드/실기기/배포는 아직 수행하지 않음. 웹 PR은 운영에 미병합.

## 탭별 요구사항(구현과 설계를 구분)
### 사진
- 셔터음은 기기·지역 정책에 따르되 합법/지원범위에서 조용한 확인음 옵션. 강제 셔터음 제거/위장음 보장 금지.
- 0.6,1,2,3,10,30배 렌즈 지원범위에 따른 선택/핀치줌/부드러운 줌; CameraX 논리렌즈 노출 한계 표시.
- 얼굴/눈 우선 자동초점, 풍경 전체 선명 모드, 아이 움직임 셔터, 선명도 사전 검사, HDR/밤/음식/사진관 인물·긴 다리 보정/화이트톤, 원본별도 저장
- SNOW 수준 자연 얼굴 보정과 AR 고양이/토끼/왕관·재미 효과·AI 나이변환/후처리, 가족 다인 추적
- 하츄핑/실바니안/뽀로로 공식 캐릭터는 사용허락 확인; 미허락시 독창적인 하트 요정·동물 인형·펭귄 테마
### 동영상
- 사진과 동일 필터/추적·초점·배율·흔들림 조정, 음성 강조·AI 배경 소음 제거(실시간/후처리 분리), 원본/보정본
- 녹화는 사용자 명시 시작, 홈/화면꺼짐은 앱이 보이는 중 시작한 camera foreground service로 유지 시도. 상시 녹화 상태/알림/종료. 기기 강제종료·재부팅 후 자동 재시작 금지.
### 책·문서·제본 PDF
- 자동 페이지 인식, 접힌 책 곡면/원근/그림자·손가락 제거, 좌우 분할, 자동 1초/2초 안정화 촬영, 한국어 OCR, 검색층 PDF, 원본·보정본·OCR 모두 보존
- 제본 용지 A4/A5/B5, 양면/표지/목차/페이지 번호/누락검출/제본여백·표 숫자 과보정 방지, Google Drive 백업
- Google ML Kit 문서스캐너는 이미지 PDF 생성 구현 진입만. vFlat급 책 곡면 처리, 검색 PDF 및 상세 제본 엔진 미구현
### 수목
- 카메라 프리뷰에서 나무 검출 및 '소나무 추정' 등 수종 상위 2-5 후보, 분류 근거와 유사 수종·고가 수목 주의
- AR H/B/R/W 실제 깊이·거리 기반 추정, 3D 검출 불가능 시 가짜 숫자 금지, 모바일 사진·현장 조사표·GPS·감정평가 AI 연결
- 웹 Pl@ntNet 서버 키 설정이 필요. 네이티브 대분류 ML Kit은 식물만 감지. H/B/R/W 자동 측정 및 나무별 분할 미구현. ARCore는 사용자 포인트 선택·거리/면적 측정
### 골프
- FHD240/UHD120 고속은 기기/SDK 지원 확인 후 실제 촬영 모드, 자동 시작·종료·단계/임팩트 추적·정면/다운더라인·클럽·타점·힘의 방향 검토
- 프로 영상과 7단계 비교, 특정 관절각·개인 자세 변화·교정 1개/연습 5회 안내, 샷 구질/탄도·탄착/스윙 정확도 연결
- 웹: 파일 비교, 2D 관절각, 임팩트 후보와 미션 저장 코드. 네이티브 240fps/클럽 추적·완전 개인 샷 연동 미구현
### 번역
- 카메라 라이브 OCR→한글 번역 겹쳐 표시, 외국어 메뉴/간판/문서, 음성 번역은 별도 파이프라인
- 네이티브 소스: 라틴 문자→한국어 번역 모델 기반 텍스트 영역 결과. AR 박스 위치 안정화 미구현
### 측량
- 측량 메인: 거리, 면적, 건물 외벽, 실내 바닥/공간, 골프 거리, 나무 H/B/R/W
- 3D 기준: ARCore Session/Depth/HitTest/세계좌표+자세 추정, 점 2개 거리, 평면상의 다각형 면적, 화면 위 추정값/신뢰도
- 야외 Scene Semantics TREE/BUILDING 자동 대분류. 건물·실내 구조를 이동 중 자동 3D 메시로 복원하는 기능은 미구현.
- 건물 외벽 면적/실내 바닥 면적은 실제 건축면적·연면적과 다름, 현장 참고치와 실측 별도 관리

## 구현 합격 기준
1. Android Studio 릴리스/디버그 APK 빌드 성공, 폴드7 실제 권한·성능 테스트
2. 사진/영상/문서/번역·미리보기 FHD+ 밝기·노이즈·부하/배터리 테스트, 원본 보존
3. 홈/화면꺼짐/통화/재부팅/강제종료 후 프라이버시·녹화 알림·녹화파일 무결성 테스트
4. AR 1m,3m,5m,10m 길이/면적 기준 줄자·레이저 계측 30회 이상 반복 오차표, 무늬 없는 벽·유리·지붕에서 미측정 표시
5. 수종 교차검증 100종+ 유사 수종/크기/계절, H/B/R 실제 줄자·수고계 교차검증, 근원부 가림/편평 줄기
6. 골프 프로/자기 영상 동일 시점 비교 정확도, 고속 영상 실제 메타데이터 FPS 확인, 관절 누락·프레임간격 오차
7. OCR PDF 검색성·곡면/서적 100페이지 누락/순서/표 숫자 검증
8. 실기기 검증 전 '완료' 표시 금지.
