# AI 카메라 ↔ Golf AI: 골프 초슬로모션 공유 모듈

## 목적
- 기존 Golf AI 스윙 분석 탭과 AI 카메라의 골프 진입점(/camera/golf)에서 같은 SwingStudio 컴포넌트 사용
- 기존 코스·캐디·점수·연습 기능 보존, 새 기능은 격리된 클라이언트 컴포넌트로 추가
- 로컬 동영상만 처리. 영상의 외부 서버 자동 업로드 없음. MediaPipe 모델 코드/가중치는 최초 분석 시 외부 CDN에서 내려받음

## 현재 구현
1. 내 영상 / 허가받은 프로 참고 영상 불러오기
2. 브라우저에서 직접 카메라 미리보기 / 일반 영상 녹화 (실제 fps 표시)
3. 30·60·120·240fps 수동 기준 프레임 전·후 이동, 1x/0.5x/0.25x/0.125x 재생
4. 7개 스윙 단계(어드레스·테이크백·백스윙 탑·전환·다운스윙·임팩트·피니시) 시점 수동 표시 및 양 영상 맞춤
5. MediaPipe 33점 자세 추정 기반 관절 오버레이 및 어깨/골반/상체/팔꿈치/무릎 2D 기하 각도 표시
6. 해당 단계의 프로/내 영상 각도 차이 정렬, 가장 큰 차이를 한 문장으로 피드백 + 한국어 TTS

## 기기 지원 및 주의
- 삼성 Z Fold7 삼성 공식 규격: FHD 240fps, UHD 120fps. 기본 카메라 지원과 웹 카메라/서드파티 SDK 지원은 다름
- 240fps를 확보하려면 폴드7 기본 카메라에서 촬영 후 웹앱에 불러오는 경로가 우선
- 웹 MediaRecorder는 브라우저/카메라에서 노출된 FPS로 녹화됨. 카메라 설정의 실제 frameRate 표시; 240fps라고 속이지 않음
- 파일의 실제 fps를 브라우저가 자동으로 제공하지 않는 경우가 많아 사용자가 분석 기준 fps를 선택함. 이미 30fps로 변환된 슬로모션 파일은 30 선택
- 2D 영상의 측정치는 촬영 방향, 각도, 가림, 영상 압축 및 체형에 민감함. 프로 스윙과 다르다고 틀린 자세인 것은 아님
- 클럽헤드·샤프트·페이스/정확한 임팩트·체중 이동·볼스피드/타점 추적은 아직 지원하지 않음. 생크/뒤땅 원인을 2D 자세 차이만으로 확정하지 않음

## 이후 구현·검증 (아직 완료 아님)
- Android CameraX 1.5 고속 촬영 지원 질의와 기기별 지원 프레임레이트 목록을 기반으로 진짜 120/240fps 네이티브 촬영 모드
- 삼각대 후면/정면 안내, 촬영 세션 연속 자동 분할, 음성·화면 즉시 코칭
- 스윙 7단계 자동 검출과 전후 비교 동기화, 골프채/볼 추적 (실제 검증 필요)
- 골프 AI 내 연습/코칭 미션과 클럽별 스윙 기록 영구 연결
- 폴드7/플립3 실제 촬영 비교, 60/120/240fps 유효 파일 분석, 모델 오검출·현장 빛 번짐 테스트
- 저작권·초상권 및 개인 동영상 사용 권한 확인 후 프로 참고 동영상 활용
