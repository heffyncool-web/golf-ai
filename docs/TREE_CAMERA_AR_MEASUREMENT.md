# AI 카메라 수목 인식·규격 측정 통합 (Prototype)

## 현재 코딩된 기능
- /camera/trees: Android/desktop HTTPS 웹 카메라 시작·종료
- 1회 촬영 또는 사용자가 직접 켜는 18초 간격 자동 수종 추정
- 실시간 카메라 프리뷰 하단에 가장 최근의 수종 추정 결과와 모델 점수 오버레이
- Pl@ntNet 이미지 식별 서버 연계 (1개 나무 / 1회 1개 사진 / 서버 비밀키 PLANTNET_API_KEY 필요)
- 소나무, 곰솔, 잣나무 등 한국의 주요 수종 영문 학명→한국어 명칭 매핑 + 상위 5개 후보
- 촬영 원본 업로드 또는 영상 캡처, 동일 거리·평면의 21cm A4 등 참조물 양 끝과 나무 줄기 양 끝을 점 지정해서 B/R 직경 *참고값* 계산
- 현장조사 추정 기록 추가 및 CSV 내보내기 (페이지 이동 시 세션 삭제)
- ARCore 네이티브 개발자가 사용하도록 3D 좌표에 의한 H/B/W 환산 유틸리티 별도 작성
- 서버 설정 누락·미지원 기기에서 허위 '소나무' 결과나 지름·높이 값은 출력하지 않음

## 운영 환경 준비
- 반드시 프리뷰 배포 및 접근 인증, 업로드 허용량 제한 이후 공개
- 서버 환경변수 PLANTNET_API_KEY를 안전하게 저장. 웹 클라이언트 JS에 절대 노출하지 않음
- 요청 IP 기반 단순 rate limit은 다중 서버 인스턴스에 걸친 전체 한도가 아니므로, 공개 운영 전 사용자 로그인과 서버 공유 rate limiter 적용
- Pl@ntNet에서 무료 계정 및 API 키를 생성해야 서버 기반 인식을 사용할 수 있음
- 자동 반복 요청은 명시적인 ON/OFF, 18초 간격, 세션 15회 제한. 앱 백그라운드에서 자동 전송하지 않음
- 카메라 영상의 사람 얼굴/등록번호판/위치 문서가 외부 서비스로 전송될 가능성이 있으므로 안내하고 동의 받은 장면만 분석
- API 응답 점수는 분류기의 추정이며 국내 수종 확정과 보상평가의 검증된 신뢰도가 아님

## 폴드7 전용 ARCore Depth API 다음 단계
- 공식 ARCore 지원 목록에 Galaxy Z Fold7 Depth API 지원으로 표기됨
- Depth mode AUTOMATIC, RawDepth confidence 지원 확인, Google Play Services for AR 런타임 검사
- 장면의 나무를 포인터로 가리키면 수종 후보를 먼저 표시. 같은 나무의 잎·수피·열매 이미지로 추가 검증
- 사용자가 밑동/꼭대기를 태깅하면 AR world 좌표 수직 차이로 H(m) 추정. 장거리·키 큰 나무는 오차 검증
- 흉고직경 B(cm): 지상 1.2m 수간 양끝의 깊이 기반 3D 점을 구해 거리 추정
- 근원직경 R(cm): 지표면에 접하는 수간 단면의 좌·우 경계와 지표면을 확인
- 수관폭 W(m): 수관 양끝 3D 거리, 수평 성분 기반 계산
- raw depth confidence/거리/추적 상태에 따라 신뢰도 표기. 거리 0.5~5m에서 유리. 수고는 광각 전환과 나무 꼭대기 추적 어려움에 주의
- 조경수 B 1.2m 기준, R 지표면 접점, 다른 기관·평가목적의 정의는 별도 저장
- AR 측정이 불가능하면 크기 숫자를 가상으로 제시하지 않고 실측 확인 요청
- 보상감정서 내 수종/규격/본수 확정치는 평가사 실측·기준 확인 후에만 인정

## 검증 필요
- 폴드7 ARCore 실제 깊이값과 레이저 거리계/줄자/캘리퍼스의 오차 표본
- 근원부 방해물·갈라진 줄기·곡선 수간·고가 조경수·유사 수종 혼동
- 클라이언트 과금·인식 제한과 사용자 인증, 지속 저장, 오프라인 모델 학습/배포
- 실제 독립 Android Camera 앱 프로젝트에는 아직 통합되지 않음. 현재는 골프 AI 저장소 안의 웹 카메라 시안
